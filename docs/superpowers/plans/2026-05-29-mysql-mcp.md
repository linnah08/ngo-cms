# MySQL MCP Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only MySQL MCP server so Claude can query the local `detelinavasileva_oddminds` database directly.

**Architecture:** Add `@benborla29/mcp-server-mysql` as a project-scoped MCP server in `.claude/settings.local.json`. Credentials stored locally (file is untracked by git). All mutation operations disabled.

**Tech Stack:** `@benborla29/mcp-server-mysql` v2.0.8 via npx, MySQL 5.x/8.x on localhost.

---

### Task 1: Add MySQL MCP server to project settings

**Files:**
- Modify: `.claude/settings.local.json`

- [ ] **Step 1: Read the current settings.local.json**

Read `/Users/detelinavasileva/Code/oddminds/.claude/settings.local.json` to see the existing structure before editing.

- [ ] **Step 2: Add the mcpServers block**

Merge the following into the top-level JSON object in `.claude/settings.local.json`:

```json
"mcpServers": {
  "mysql": {
    "command": "npx",
    "args": ["-y", "@benborla29/mcp-server-mysql"],
    "env": {
      "MYSQL_HOST": "localhost",
      "MYSQL_PORT": "3306",
      "MYSQL_USER": "master",
      "MYSQL_PASS": "Mr4zqz1m4!",
      "MYSQL_DB": "detelinavasileva_oddminds",
      "ALLOW_INSERT_OPERATION": "false",
      "ALLOW_UPDATE_OPERATION": "false",
      "ALLOW_DELETE_OPERATION": "false",
      "ALLOW_DDL_OPERATION": "false"
    }
  }
}
```

The final file should look like:

```json
{
  "permissions": {
```

- [ ] **Step 3: Verify JSON is valid**

Run:
```bash
python3 -c "import json; json.load(open('.claude/settings.local.json')); print('valid')"
```
Expected output: `valid`

- [ ] **Step 4: Smoke-test the MCP server starts**

Run:
```bash
MYSQL_HOST=localhost MYSQL_PORT=3306 MYSQL_USER=master MYSQL_PASS="Mr4zqz1m4!" MYSQL_DB=detelinavasileva_oddminds ALLOW_INSERT_OPERATION=false ALLOW_UPDATE_OPERATION=false ALLOW_DELETE_OPERATION=false ALLOW_DDL_OPERATION=false npx -y @benborla29/mcp-server-mysql &
MCP_PID=$!
sleep 5
kill $MCP_PID 2>/dev/null
echo "exit: $?"
```
Expected: process starts without error (exit 0 after kill). If it exits immediately with an error, check that MySQL is running (`mysql -u master -pMr4zqz1m4! detelinavasileva_oddminds -e "SELECT 1"`).
