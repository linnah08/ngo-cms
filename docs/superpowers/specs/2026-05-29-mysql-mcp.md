# MySQL MCP Server — Design Spec

**Date:** 2026-05-29  
**Status:** Approved

## Goal

Give Claude direct read access to the local `detelinavasileva_oddminds` MySQL database so it can inspect order state, verify migrations, and check production data without routing through PHP scripts or SSH.

## Approach

Add `@benborla29/mcp-server-mysql` (v2.0.8, npm) as a project-scoped MCP server in `.claude/settings.local.json`.

## Configuration

- **Host:** localhost:3306  
- **User:** master  
- **Database:** detelinavasileva_oddminds  
- **Mutations:** blocked (INSERT, UPDATE, DELETE, DDL all disabled)  
- **Credential storage:** `.claude/settings.local.json` (untracked by git)

## What changes

| File | Change |
|------|--------|
| `.claude/settings.local.json` | Add `mcpServers.mysql` block with env vars and mutation flags |

No other files change. No migrations. No new dependencies installed globally — `npx -y` fetches the package on first use.

## What stays the same

SSH permissions (`Bash(ssh oddminds *)`) remain for the rare cases where Claude needs to mutate production data directly.

## Error handling

If the MCP server fails to start (e.g., MySQL not running locally), Claude falls back to the existing Bash/SSH workflow. No breakage.
